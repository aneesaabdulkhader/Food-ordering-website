🍔 Campus Food Hub

About the Project

Campus Food Hub is a simple food ordering website designed for college students. Students can view the canteen food menu, add items to their cart and place orders easily.

Features

- View food menu
- Add food items to cart
- Increase food quantity
- Remove food items
- Calculate total price
- Place orders

Technologies Used

- HTML
- CSS
- JavaScript

Project Structure

Campus-Food-Hub/

- index.html
- style.css
- script.js
- README.md

How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open index.html in a browser.
4. Start ordering food!
